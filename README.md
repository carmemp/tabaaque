Lançamento: Coleção Halloween (50 peças, até 31/10).

  - `prototipo/sobre.html`: a história da marca
- **Textos:** [conteudo/textos-do-site.md](conteudo/textos-do-site.md)
- **Briefing do Gabriel:** [briefing/briefing-gabriel.md](briefing/briefing-gabriel.md)
